My Projects

Website Development Project

This project focused on building a structured multi-page website using HTML and CSS. I created a consistent layout using semantic elements such as headers, navigation, main sections, and footers. I also used external CSS to maintain consistent styling across all pages. This project helped me understand how websites are structured and how navigation connects multiple pages into a single cohesive system.

I learned the importance of organization and consistency when building websites. One challenge was keeping navigation links working across multiple pages. I improved my ability to write clean, reusable code and structure a full website. In the future, I would enhance this project with more interactive features and improved design styling.

Financial Literacy App Concept

This project involved designing a financial literacy application to help users manage budgeting, saving, and spending habits. I created feature ideas such as expense tracking, savings goals, and educational tools. The goal was to design a simple and user-friendly interface that makes financial concepts easier to understand and apply in daily life.

I learned how to simplify complex financial topics into usable app features. One challenge was deciding which features were most important for users. I improved my understanding of user experience design and prioritizing functionality. If expanded, I would build a working prototype and test it with users.

StorySync Interactive Platform

StorySync Interactive is a concept for an immersive storytelling platform where users participate in real-time, location-based narratives. The experience uses branching storylines where user decisions affect the outcome. I focused on designing interaction flow, engagement systems, and how users would move through story events.

This project helped me think beyond traditional websites and explore interactive systems. One challenge was balancing storytelling with usability so users would not feel overwhelmed. I improved my ability to design large-scale concepts and break them into smaller parts. If developed further, I would create a prototype to test user interaction.
