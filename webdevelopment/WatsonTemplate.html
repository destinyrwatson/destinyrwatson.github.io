Website Development Project

This project focused on building a structured multi-page website using HTML and CSS. I created a reusable template with consistent navigation, headers, and footers across all pages. I used semantic HTML elements to organize content and external CSS to maintain a consistent design. This project helped me understand how websites are structured and how different pages connect through navigation systems.

I learned the importance of clean code organization and consistency across pages. One challenge was making sure all navigation links worked correctly. I improved my understanding of web structure and how to build scalable websites. I would improve this project by adding more interactivity and visual enhancements.

Financial Literacy App Concept

This project involved designing a financial literacy application that helps users manage budgeting, saving, and spending. I developed features such as expense tracking, savings goals, and educational tools. The focus was on creating a simple and user-friendly interface that makes financial concepts easier to understand.

I learned how to simplify complex financial topics into practical app features. One challenge was deciding which features would be most useful for users. I improved my ability to think from a user experience perspective. If developed further, I would build a working prototype and test it with real users.

StorySync Interactive Platform

StorySync Interactive is a concept for an immersive storytelling platform where users participate in real-time, location-based narratives. The project combines live actors, mobile interaction, and branching storylines where user choices influence outcomes. I focused on designing how users would interact with stories, including decision points and engagement features that make storytelling more dynamic and immersive.

This project helped me think beyond traditional web design and explore interactive experiences. One challenge was balancing storytelling with usability so users wouldn’t feel overwhelmed. I improved my ability to design large-scale concepts and break them into smaller components. If developed further, I would create a prototype to test user interaction in real-time scenarios.
