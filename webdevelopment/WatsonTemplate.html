Starter Website Template

This project focused on building a foundational HTML template that could be reused across multiple pages of a website. I used semantic structure including header, navigation, main, and footer elements to create a consistent layout. I also linked external CSS files and applied Google Fonts to improve typography and consistency. The navigation system was structured using lists to ensure usability and organization. This helped me understand how websites are structured and how pages connect together.

I learned the importance of clean structure and planning before styling a website. One challenge was keeping navigation consistent across pages. I improved my ability to organize code and build reusable layouts. I would improve this project by adding more interactive elements and enhancing visual design.

Responsive Layout Design

This project focused on creating a responsive webpage using CSS Grid, Flexbox, and media queries. I designed layouts that adjust across desktop and mobile screens. Grid was used for structure while Flexbox helped align content inside cards. Media queries were used to change layout and font sizes for smaller screens. This project showed me how important responsive design is for modern websites.

I learned how to combine Grid and Flexbox effectively. One challenge was making sure the layout did not break on smaller screens. Testing different screen sizes helped me fix issues. I would improve this by refining spacing and experimenting with more advanced layouts.

Financial Literacy App Concept

This project involved designing a concept for a financial literacy application that helps users manage budgeting, saving, and spending. I outlined features such as expense tracking, savings goals, and educational tools. I focused on creating a simple and user-friendly interface that makes financial information easy to understand and access.

I learned how to simplify complex topics into usable features. One challenge was deciding which features were most important. I improved my ability to think from a user experience perspective. If developed further, I would build a prototype and test it with users.
